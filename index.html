GitHub · consola

Tu primer flujo
con Git

Git registra cambios en tu proyecto; GitHub guarda una copia remota para compartir y colaborar. Estos comandos cubren el ciclo básico: descargar, modificar, guardar y publicar.

Antes de empezar

Instala Git, abre PowerShell o Terminal y asegúrate de tener acceso a tu cuenta de GitHub. No pegues contraseñas ni tokens en la consola.

01

Configura tu identidad

Solo se realiza una vez en cada equipo. El correo debe coincidir con uno verificado en GitHub.

Terminalgit config --global user.name "Tu Nombre"
git config --global user.email "tu-correo@ejemplo.com"
02

Descarga un repositorio

En GitHub, abre el repositorio, pulsa Code y copia su dirección HTTPS. Luego ejecuta:

Terminalgit clone https://github.com/usuario/nombre-del-repo.git
cd nombre-del-repo
03

Guarda tus cambios

Después de editar archivos, revisa qué cambió, prepara esos cambios y crea un punto de guardado con un mensaje claro.

Revisargit status

Te muestra archivos nuevos, modificados o listos para guardar.

Preparargit add .

Incluye todos los cambios del proyecto. Para un archivo: git add archivo.html.

Guardargit commit -m "Describe el cambio"

Escribe mensajes breves y concretos, por ejemplo: "Agrega sección de aprendizaje".

04

Publica y actualiza

Envía tu commit a GitHub. Antes de comenzar a trabajar otro día, descarga los cambios remotos.

Subir a GitHubgit push origin main

Puede pedirte autenticarte en GitHub la primera vez.

Traer cambiosgit pull origin main

Hazlo antes de editar si alguien más trabaja en el mismo proyecto.

Un hábito útil

Usa git status antes de git add .. Así evitas subir archivos que no pertenecen al proyecto, como claves, contraseñas o configuraciones privadas.
